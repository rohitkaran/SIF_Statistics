How this is built

AMFI publishes NAVs for SIFs but no AUM feed — there is no sif-aum endpoint of any kind. Every figure here therefore comes from the fund houses themselves: each portfolio disclosure states the scheme's net assets, and we normalise those filings into one schema. One portfolio file counts as one fund; Direct/Regular and Growth/IDCW variants are never added together.

Why there is no month-by-month industry chart. SIF houses disclose on a staggered, roughly bi-monthly cycle — consecutive months contain almost entirely different fund houses. Differencing two months would compare one set of AMCs against another and report that composition change as "growth", which would be wrong. So a fund is only ever compared against its own previous disclosure, and the gap between them is stated.

Figures are disclosed net assets as at each fund's own disclosure date, reproduced for information only. They are not investment advice and not a measure of fund quality — size is not performance. Verify against scheme documents before relying on them.
